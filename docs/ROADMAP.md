# Roadmap de implementação

- F1: auth OIDC, memberships, convite, RLS, CI, banco.
- F2: OpenClaw Adapter real, runtime provisioner, reconciler, health, isolamento.
- F3: Agent Builder, versões, templates, BYOK com Vault, RAG.
- F4: conversas persistentes, streaming, Tool Gateway, MCP e execução.
- F5: políticas, approvals, budgets, ledger, billing, auditoria e segurança.
- F6: onboarding, checkout, dashboards, documentação, piloto.
- F7: Teams com canais, DMs, menções, Agent Router, tarefas e notificações.
- F8: workflow engine, n8n licenciado, cloud computer, desktop connector, local runtime.

Nenhuma fase está concluída. O código presente é uma base incremental para integração.
